# Student Monthly Budget Analyzer 💰

## 📌 Project Overview

Student Monthly Budget Analyzer is a beginner-friendly Python command-line application designed to help students understand and manage their monthly income and expenses.

The program collects monthly income and different expense categories, calculates total expenses, remaining balance, and savings rate, and displays a clear monthly budget report.

## 🎯 Project Objectives

- Understand Python fundamentals.
- Practise variables and data types.
- Learn user input and output.
- Perform mathematical calculations.
- Understand type conversion.
- Calculate expenses and savings percentages.

## ⚙️ Features

- Collect student name and monthly income.
- Record food expenses.
- Record travel expenses.
- Record study material expenses.
- Record mobile and internet expenses.
- Record other expenses.
- Calculate total monthly expenses.
- Calculate remaining balance.
- Calculate savings rate.
- Display a formatted budget report.

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Open the project folder in VS Code or PyCharm.
4. Run the Python file:

   ```bash
   python main.py
   ```
